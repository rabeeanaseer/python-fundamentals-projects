
# 🐍 10 Beginner Python Projects – First Semester Collection

A curated collection of 10 beginner-friendly Python projects designed for university students, programming beginners, and anyone starting their Python journey.

Learn programming by building real, practical applications. Each project focuses on fundamental Python concepts and helps you develop problem-solving skills through hands-on practice.

---

## 📌 About This Repository

Starting programming can feel overwhelming when you're only learning syntax and theory. The best way to understand programming is to build something yourself.

This repository brings together 10 practical Python projects that cover essential first-semester programming concepts, including:

- Variables and Data Types
- User Input and Output
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Functions
- Lists, Tuples, and Dictionaries
- String Manipulation
- Random Number Generation
- Basic File Handling
- CRUD Operations
- Basic Date and Time Handling

### Who is this repository for?

- First-semester Computer Science and Software Engineering students.
- Beginners learning Python from scratch.
- University students looking for programming project ideas.
- Self-learners who want practical coding experience.
- Anyone preparing for introductory programming assignments.

## ⚙️ Getting Started

### 1. Prerequisites

Before running these projects, make sure you have:

- Python 3.x installed.
- A code editor such as Visual Studio Code or PyCharm.
- Basic familiarity with using a terminal or command prompt.

Check your Python installation:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/python-beginner-projects.git
```

### 3. Navigate to the Repository

```bash
cd python-beginner-projects
```

### 4. Run a Project

Navigate to the project folder you want to explore:

```bash
cd 01-student-gpa-calculator
python main.py
```

> **Note:** Some projects may create local text (`.txt`) or CSV (`.csv`) files to store data.

## 💡 How to Use This Repository

If you're learning Python, follow these recommendations:

- **Start with the basics:** Understand the concepts used in each project before exploring the code.
- **Don't just copy:** Try implementing the solution yourself first.
- **Experiment:** Change the program's functionality and test different inputs.
- **Understand the logic:** Focus on why the code works, not just what it does.
- **Build independently:** Once you understand a project, try creating your own version.

The goal is not simply to complete 10 projects. It is to develop the programming fundamentals needed to build more advanced applications.
